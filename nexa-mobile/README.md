# Nexa Mobile

Aplicativo mobile inicial da Nexa em Expo + React Native.

## Como rodar

1. Suba estes arquivos no GitHub.
2. Abra no GitHub Codespaces ou no seu computador.
3. Rode `npm install`.
4. Rode `npm start`.
5. Escaneie o QR Code com o app Expo Go.

Backend configurado:

https://nexa-backend-p2u0.onrender.com/api/v1
